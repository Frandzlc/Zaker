# ذاكر 📚✨: مساعد مذاكرة بالذكاء الاصطناعي

تضيف كتاب PDF أو تلصق نص، والذكاء الاصطناعي (Google Gemini) يسوي لك منه:
- **اختبارات**: اختيار من متعدد وصح وخطأ، وتحدد العدد والصعوبة والصفحات. بعد كل سؤال يشرح لك الجواب ويذكر رقم الصفحة، وفي الأخير يعطيك نتيجتك ويراجع معك أخطاءك.
- **ملخصات**: مختصرة أو مفصّلة، فيها نقاط ومصطلحات مهمة.
- **بطاقات مراجعة**: سؤال من قدام وجواب من ورا، وتقدر تعيد اللي ما عرفتها.
- **اسأل الكتاب**: محادثة مع الـAI عن محتوى الكتاب.
- **ملاحظاتي**: تكتب ملاحظاتك لكل كتاب، وتقدر تحفظ فيها أي جواب أو ملخص.
- **قارئ PDF** داخل التطبيق.
- **يفتح أي ملف**: PDF، صور، Word، PowerPoint، Excel، EPUB، نصوص، صوت وفيديو. وتقدر تفتح أي ملف من تطبيق ثاني بـ «مشاركة ← ذاكر».
- **دفاتري بالقلم** ✍️:
  - أقلام حبر ورصاص وهايلايتر وفاين لاينر وريشة خط عربي وألوان مائية وشمعية، بأي مقاس.
  - **مكتبة أقلام وألوان ضخمة** فيها أكثر من ٣٥٠ لون، ومجموعات أقلام جاهزة (مدرسة، رياضيات، خط عربي، إنجليزي، فسفوري، باستيل، رسم، سبورة)، وتقدر تسوي مفضلتك.
  - ممحاة، وتحديد بالحبل (Lasso)، ومسطرة، وتراجع وإعادة.
  - **ورق مسطر بكل الأنواع**: مسطر عربي (الهامش يمين) وإنجليزي (الهامش يسار)، تحسين خط عربي وإنجليزي، خط عربي بنقاط القياس، مربعات رياضيات، ورق رسم بياني، نقاط، مستوى إحداثي، متساوي القياس، خطوط أعداد، كورنيل، عمودين، قائمة مهام، نوتة موسيقية، وغيرها. وفيه ٩ ألوان للورق منها أسود وسبورة.
  - إضافة **صور** من الألبوم أو الكاميرا، وإضافة **نصوص**، وتقدر تحركها وتكبرها.
  - **تسجيل صوت** مع كل دفتر، تسمعه وتشاركه.
  - تكتب على صفحات كتاب PDF، أو تستورد PDF وصور كصفحات.
  - تصدير الدفتر PDF أو مشاركة الصفحة كصورة.
- **الواجهة بالعربي والإنجليزي.** وتختار لغة الاختبارات والملخصات: عربي، أو إنجليزي، أو نفس لغة الكتاب.

## ١) طلّع ملف IPA
1. في GitHub سوّ مستودع جديد **Public** باسم `Zaker`.
2. ارفع محتويات المجلد. ما تفرق إذا رفعتها داخل مجلد أو في الصفحة الرئيسية، ملف البناء يلقاها في الحالتين.
3. إذا مجلد `.github` ما انرفع، روح **Actions** ← **set up a workflow yourself**، والصق محتوى ملف `build.yml`، ثم **Commit**.
4. انتظر البناء ✅ في **Actions**، ونزّل **Zaker-ipa** من قسم Artifacts.
5. ثبّته بـ **Sideloadly** بنفس طريقة تطبيق هللة.

## ٢) مفتاح Gemini (مجاني)
1. افتح **aistudio.google.com/apikey** وسجّل دخول بحساب Google.
2. اضغط **Create API key** وانسخه.
3. في التطبيق روح **الإعدادات** ← الصق المفتاح ← **حفظ المفتاح**. بعدها لازم يطلع لك «المفتاح شغّال ✅».

> إذا طلع لك خطأ إن الموديل غير موجود، أو إنك وصلت الحد، غيّر الموديل من الإعدادات.

## الخصوصية
الكتب والملاحظات محفوظة على جوالك. الكتاب ينرسل لـ Gemini بس لما تطلب اختبار أو ملخص أو تسأل سؤال، وGoogle تحذف الملفات المرفوعة تلقائيًا بعد ٤٨ ساعة.
